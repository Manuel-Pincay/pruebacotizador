Paso 2 — Contraseña de aplicación

Para Outlook / Hotmail:

Importante: Microsoft desactivó el envío SMTP en cuentas personales @hotmail.com / @outlook.com. Aunque use contraseña de aplicación, puede aparecer «basic authentication is disabled». No es un fallo del ERP. Si le pasa, use Gmail o un servicio como Brevo (gratis).
  1. Entre a account.microsoft.com → Seguridad
  2. Active la verificación en dos pasos (si no la tiene)
  3. Busque Contraseñas de aplicación y cree una nueva
  4. Copie la contraseña generada y péguela abajo

⚠ El correo debe ser exactamente el de la cuenta donde creó la contraseña de aplicación.

Para Gmail:

  1. Entre a Contraseñas de aplicación de Google
  2. Cree una contraseña para «Correo»
  3. Copie los 16 caracteres y péguelos abajo

En Yahoo: Configuración → Seguridad → Generar contraseña de aplicación.
